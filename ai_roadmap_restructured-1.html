The training loop — memorise this
for epoch in range(epochs):
    for inputs, labels in dataloader:
        preds = model(inputs)          # forward pass
        loss  = criterion(preds, labels)
        optimizer.zero_grad()          # clear old gradients
        loss.backward()                # compute new gradients
        optimizer.step()               # nudge weights downhill

Phase 3 ★ NEW Production RAG Engineering Months 9–12 ▼

The phase most AI courses skip entirely. Anyone can build a RAG demo. Building one that a healthcare firm, law firm, or financial institution relies on — with 20,000+ documents, compliance requirements, and messy real-world data — is what companies pay $50K–$200K+ for. This phase is built from the direct experience of engineers who have done exactly that.

Why RAG isn't going away: Even 200K-token models choke after ~100–200 pages. Enterprise repositories are 1,000× bigger. Usable context is really ~120K before quality drops. Fine-tuning ≠ knowledge injection — it changes style, not content. You can teach terminology but can't inject 50K docs without catastrophic forgetting. Enterprises also need audit trails + real-time compliance — RAG solves this, fine-tuning doesn't.
1 — Document quality & data pipeline
OCR glitch detectionMissing text identificationStructural inconsistency detectionDuplicate detection (same doc, different format)Garbage-in → garbage-out preventionPII detection before ingestion
Real lesson: One enterprise client had half their repository duplicated with tiny format changes. Metadata architecture alone consumed ~40% of total dev time. This is where most engineers underestimate the work.

Phase 4 ★ NEW Cloud Infrastructure for AI Months 12–15 ▼

You now have a production RAG system running locally. This phase moves it to the cloud and teaches you to operate AI workloads at scale. Cloud is the default deployment target for everything that follows — agents, MLOps, distributed training all require this foundation.

Why cloud comes before agents: Agents require cloud compute, GPU instances, managed Kubernetes, cloud storage, and scoped IAM. Building agents on local infrastructure produces habits you'll have to unlearn. Cloud first means every phase after this is built on real infrastructure.
1 — Cloud fundamentals (start with GCP — best free tier for AI)
Regions, availability zones, VPCsCompute: EC2 / GCE / Azure VMsStorage: S3 / GCS / Azure BlobNetworking: subnets, security groups, load balancersIAM: roles, policies, least privilegeBilling alerts — set on day 1
GCP is recommended first: Free $300 credit, Colab already uses Google infrastructure, GKE Autopilot has a free tier, Vertex AI free quotas. Learn AWS second — it's the enterprise standard.

Phase 7 AI Security — Defensive Architecture & Red Teaming Months 20–21 ▼

AI introduces attack surfaces that don't exist in traditional software. Prompt injection, tool hijacking, data poisoning — real threats in production today. This phase teaches defensive reasoning through attack understanding: not exploitation, but comprehension.
